水声降噪模型 — 泛化能力实验报告

2×2 因子设计（波形 × 信道）+ 分支消融 · 数据：D:/project/dataset_v3 （10,600 样本，5.25 GB）· 2026-10-13

一句话结论

模型对「没见过的新信道」泛化几乎零代价。
表面上看，新信道的增益（+11.93 dB）比见过的信道（+14.05 dB）低 2.1 dB。 但把「信道难度」控制住之后，这个差距只剩 0.3 ~ 0.4 dB —— 因为抽作测试的 4 个信道恰好是全 25 个信道里时延扩展最大的 4 个。
同时，对「没见过的新波形」的泛化代价约 0.09 dB（可忽略）。
消融还发现：仅频域分支（1,910 参数，完整模型的 1/30）就拿到 98% 的性能， 时域分支只值 0.20 dB。

一、这个实验要回答什么

上一版（v2）留下的最大缺口：测试集用了 3 组从未参与训练的 chirp 波形， 这验证了「波形泛化」；但25 个信道全部出现在训练集里， 所以无法回答一个更关键的问题：换成没见过的信道，模型还行不行？
如果模型只是"记住了这 25 个信道的多径结构"，那它在真实场景（信道未知且时变）就毫无价值。

四、关键分析：那 2 dB 差距其实不是"泛化"造成的

testA 与 testB 之间差 2.1 dB。如果直接下结论说"信道泛化有 2 dB 代价"，那是错的 —— 因为被抽作测试的 4 个信道（22–25）不是随机抽的，它们的时延扩展全部落在分布的高端：

分组时延扩展 范围中位
训练信道 1–185.8 ~ 102.8 ms70.1 ms
验证信道 19–219.0 ~ 87.7 ms74.1 ms
测试信道 22–2597.0 ~ 108.9 ms102.0 ms

也就是说，测试信道全都是"最难"的那一类。而上一轮已经查明：时延扩展越大，降噪增益越低 （在 v2 的 25 个信道上，r = −0.862）。

做法：用 v2 的数据（25 个信道全部见过）拟合"增益 ~ 时延扩展"， 得到 增益 = 16.21 − 0.0378 × 时延(ms)，r = −0.862。再外推到测试信道的时延：

测试信道时延 (ms)97.0100.0108.9104.0平均
用「见过的信道」拟合出的期望增益 (dB)12.5412.4312.0912.28 12.34
实测 vs 期望：
新信道 + 见波形（testB）实测 +11.93 dB，期望 12.34 dB → 差 -0.41 dB
新信道 + 新波形（testC）实测 +12.02 dB，期望 12.34 dB → 差 -0.32 dB
结论：把信道难度控制住以后，换成没见过的信道，性能只掉 0.3 ~ 0.4 dB。 也就是说，之前看到的"2 dB 差距"里，约 85% 来自测试信道本身更难，只有约 15% 来自"没见过"。

严格来说，测试信道的时延（97–108.9 ms）略微超出训练信道范围（5.8–102.8 ms）， 属于轻度外推。这也说明模型在训练分布边缘仍然稳定。 另外注意理想带通在 testB 上也从 12.63 降到 12.40 dB，独立印证了新信道本身更难。

五、消融实验：两个分支各贡献多少

完整模型把两个分支的残差用可学习的 softmax 权重融合。训练过程中权重一路演化：

时域分支的权重被训练到 0.006 —— 模型基本弃用了它。这是一个需要如实报告的发现。

时域 + 频域（完整模型）57,65714.0511.9312.0212.67

读法：仅频域分支的参数量只有 1,910 —— 是完整模型 57,657 的 1/30 —— 却已经追到只差 0.20 dB；而仅时域分支（55,745 参数）差了 5.5 dB。 也就是说，这个模型本质上是一个频域掩码降噪器，时域分支几乎没起作用。

这是本次实验最有价值的发现：一个 1,910 参数的频域掩码，就能拿到 57,657 参数模型的 98% 性能。 对"轻量化模型"这个题目来说，这意味着模型可以再缩小约 30 倍而几乎不掉性能。 下一步最值得做的不是"加大模型"，而是沿频域分支做尺寸扫描，找出精度-复杂度的最优拐点。

七、局限（写进报告要说明）

  • 只有 4 个测试信道，统计上偏少，而且全在高时延端。要更稳的结论，建议再做几组不同的信道划分 （例如随机抽 3 次，每次换 4–5 个信道）。
  • 测试信道是轻度外推：时延 97–108.9 ms 略超出训练范围 5.8–102.8 ms。
  • 仍然是仿真数据（RAM 仿真信道 + LFM 合成信号），不是实测。
  • 信道是静态的：真实水声信道随时间变化，本实验没有测试时变信道。
  • 降采样 4 倍的前端设计带来的输入 SNR 抬高（+6 dB）依旧存在，部署时必须一致。

八、下一步建议

  1. 沿频域分支做尺寸扫描（优先级最高）。既然 1,910 参数就够用，应该扫一遍通道宽度 （例如 0.5× / 1× / 2× / 4×），找出精度-复杂度拐点，这才是"轻量化"论文该有的核心结果。 注意：单纯加大时域分支的 hidden 是没用的（它已经被弃用）。
  2. 查清频域分支为何压倒性主导。可能的原因：损失函数（L1 + 谱 L1）天然偏向频域解； 或频域掩码本身是降噪的强归纳偏置。若确认，可以直接删掉时域分支， 代码和显存都更省。
  3. 多组信道划分重复实验，把"信道泛化代价 ≈ 0.4 dB"这个结论做扎实。
  4. 换损失：加入 SI-SDR 损失项或多分辨率 STFT 损失。
  5. 去掉零填充（v2 报告 P2）：样本有效长度中位只有 6031/8000。
