零、结论

① 按导师方案实现的 PAM-Net 可用，且远超全部经典方法。 纯时域版（8,906 参数，GroupNorm，3 种子均值）在 testA 上拿到干扰帧增益 17.29 ± 0.69 dB、干净帧 10.85 ± 0.49 dB、 干扰帧最差 9.80 ± 0.39 dB；而经典方法里最强的盲谱减法只有 6.27 / 10.51 / 1.83 dB，理想带通只有 8.00 / 5.69 / 1.65 dB。
② 但纯时域结构打不过频域掩码模型，差距 10.1 dB（干扰帧）。 推荐模型（频域精修 + p 注入，14,858 参数）的干扰帧增益是 27.38 ± 0.16 dB。原因不是实现错误，而是结构先验： 信号是窄带 chirp（798–1500 Hz），而 α 稳定背景与突发脉冲都是宽带的， 频域掩码天生等效于一个可学习的带通；纯时域残差估计必须从零学出这个带通。 这与阶段0"频域分支贡献几乎全部性能"的结论一致。
③ 脉冲感知分支确实形成了判别能力，但性能贡献很小。 该分支输出 pn 与真实干扰掩码的逐样本 AUC = 0.953 （中位 0.976，97% 的样本 > 0.8），干扰位置平均置信度 0.828 vs 干净位置 0.0027 —— 确实学到了"哪里是脉冲"。但把它接进网络后：
  · 纯时域结构里，效应精确为零（干扰帧 +0.095 dB， 跨 3 种子 p = 0.80）；
  · 只有在频域框架里才测得出（干扰帧 +0.790 ± 0.143 dB， p = 0.005，n = 5 种子；干净帧 +0.127 dB）。
但这个量级的效应还不够稳定：testC 上显著的是干净帧 （+0.260 ± 0.084 dB，p = 0.036）而干扰帧不显著， 与 testA 相反 —— 效应落在哪个指标上会随测试集变化，说明它接近当前种子数下的 可检测下限，要定论需要更多种子。
解释：二维频域掩码本身就能捕捉脉冲在时频面上的竖直条纹结构，脉冲感知分支与它高度冗余。
④ 方法学修正（必须记录）：实验协议本身会放大结论。 BatchNorm 的逐批统计量被脉冲污染 → 验证指标逐轮振荡（标准差 2.45 dB）， best-checkpoint 选择会挑到"统计量恰好有利"的轮次，带来中位 3.8 dB 的乐观偏差。 改用 GroupNorm 后振荡降到 0.68 dB、最佳轮次移到末轮（单调收敛）。
后果：BN 单种子曾给出"脉冲分支 +1.99/+1.27/+0.96 dB"，而 GN 多种子只有 +0.127（干净帧）/+0.790（干扰帧） dB —— 单种子 + BN 会把效应量夸大 2~6 倍。所有最终结论均基于 GN + 多种子。
⑤ 受控阶梯：架构是主要贡献，协议只占小头。 把"阶段0 → PAM-Net"的差距拆成每步只改一个因素的阶梯。前置验证：纯频域模式的 PAM-Net 与阶段0 的 v3.DenoiseNet(fch=2.0) 架构逐位等价 （参数量同为 5,910，前向输出最大差 0.000e+00）；且协议完全相同、只换训练管线时 结果差 ≤0.04 dB。分解结果：训练协议（损失 + 模型选择 + 归一化）合计约 -0.78 dB，架构（时域多尺度残差 + 脉冲感知注入）约 +3.07 dB （干扰帧；干扰帧最差 +0.48 / +3.10）。 此前"PAM-Net 优于阶段0"的结论成立，但现在协议成分被单独量化出来了。详见第六节。
⑥ 效应的波形依赖：真实但很小，机制不是带宽。 ① 效应是强 SNR 依赖的 —— 低 SNR 时收益全在干扰帧，高 SNR 时转到干净帧， 两个测试集是同一趋势（所以"testA/testC 不一致"的说法是错的）；
② 方差分解：波形效应真实（干扰帧 F = 4.13，p < 0.01）但只解释 3.8% 的方差， 96% 来自逐样本的干扰实现波动（SD 1.73 dB vs 波形 0.34 dB）—— 分支不是"稳定提升"，而是在个别样本上帮助或损害 ±1.7 dB、平均只 +0.37 dB 的小幅正偏置；
③ 用"固定干扰、只变波形"的配对设计（干扰最大差 1.07e−14）发现真正的机制是 干扰与信号的时频重叠率（r = -0.696，t = −4.11，p < 0.001）： 干扰越落在信号时频支撑内，分支收益越小。带宽假设被否定 （chirp 8 与 chirp 19 带宽几乎相同，收益却差 1.7 dB）。详见第七节。
⑦ 适用边界：排序稳、符号稳、但量级随条件起伏；且发现一个 SNR 定义的混杂。 把 5 个模型放到 7 个条件（α ∈ [1.2, 2.0] × 突发率 ∈ [2.5, 10]/s）上做零样本评估： 推荐模型 R5 在 全部 7 个条件 的干扰帧增益上都排第一 （唯一例外详见 8.2：高斯背景上 R4 被 R3 反超，但 R5 仍最高）， 脉冲分支效应 Δ 的符号在所有条件上一致为正（量级 0.20~1.74 dB）。 规律很清晰：α 轴单调（背景越脉冲化，收益从 +1.30 降到 +0.20 dB， α=1.2 时跨种子不显著），rate 轴反向（突发越稀疏收益越大：2.5/s 时 +0.98， 10/s 时 +0.55）—— 后者与第七节的时频重叠机制一致。 架构优势 R5−R3 也从 α=1.2 的 +4.03 dB 缩到高斯数据上的 +1.07 dB。
并用等有效功率 SNR 的重扫（8.1b）把 α 轴的混杂拆开：单调趋势的尾形成分是真实的， 但未匹配的 α 扫描夸大了它的幅度（α=1.2 端放大约 1.5 倍；α=1.8 端因强度成分反向 而几乎掩盖了尾形的增强）。
更重要的方法论发现：SNR 用"75% 分位数匹配"定义时，名义 SNR 固定 并不代表有效功率 SNR 固定 —— α 从 2.0 降到 1.2，背景噪声的有效功率信噪比从 +10.84 dB 掉到 -16.36 dB（差 27.2 dB）。 所以 α 扫描实际是"强度 + 形状"的联合偏移，不能单独解读为重尾程度的影响； 真正的单因素操纵是突发率轴。详见第八节。

1.1 文档未明确、由本实现补齐的两处

  1. 脉冲感知分支"辅助特征融合"的形式。文档只给 p_n=σ(f_imp(F)_n)， 未给融合公式。本实现把 pn 作为附加通道拼接送入下游： 纯时域版 r̂=f_θ([F_fuse;p_n])；频域版把 p 按 hop 做 max-pool 对齐到 STFT 帧率、沿频率轴广播后作为掩码网络的第 2 个输入通道。
    实验依据初版用乘性调制 F_fuse⊙(1+p_n)，实测失败： p 的分离度持续变好，验证 SNR 却从 +0.30 一路降到 −2.68 dB —— L_imp 的梯度经乘性门 直接灌进共享主干，"为了拟合掩码而破坏重建"。
  2. 感受野选取依据。数据在 6 kHz 下突发时长为 12~180 点，故长时分支取膨胀率 1/4/16（k=7）得 135 点感受野；短时分支取 k=3 两层（13 点）定位突发边缘，两者相差 10 倍。

三、归一化方式的诊断与协议修正

这是本次最重要的方法学发现，也是所有结论的前提。

训练日志显示验证指标大幅振荡。对全部 run 统计（analyze_stability.py）： 逐轮 val 帧增益的标准差中位 2.01 dB、最大 3.15 dB；最佳轮次散布在 4~14 轮； 「最佳轮 − 末5轮均值」中位 2.51 dB。也就是说 best-checkpoint 选择在挑"运气轮次"， 而它带来的乐观偏差与要论证的效应量同量级。

3.1 定位原因

输入是重尾的（α 稳定背景 + 20×rms 脉冲），逐 batch 的统计量差异极大。 BN 的 running statistics 因此被脉冲污染，eval 模式（用 running stats）与 train 模式 （用 batch stats）行为不一致。实测同一 checkpoint：

归一化统计量能把指标推动 5.3 dB —— 足以解释逐轮 2~3 dB 的振荡。

3.2 修正：改用 GroupNorm

给全部卷积层加可切换的归一化（--norm bn|gn|in）。GN/IN 不依赖 batch 统计， train 与 eval 输出逐位一致（实测最大差 0.000；BN 为 0.84）。同配置、同数据、 同超参、只换归一化的对照：

7.2 机制：不是带宽，是时频可分性

最初假设"带宽越宽 → 与宽带干扰重叠越多 → 分支越有价值"。但原始扫描集有一个 混杂：干扰的随机种子是 seed + 样本序号，而 chirp 是最外层循环， 所以每个 chirp 独占一段连续种子区间 —— 干扰实现与 chirp 序号完全混杂。

十一、独立复算

verify_pamnet.py 不复用训练脚本的任何实现：自己读 .mat、 自己 resample_poly(1,4)、自己实现 SNR / SI-SDR / 逐帧降噪增益， 再与训练脚本产出的逐样本 CSV 对比。唯一共用的是模型定义本身 （验证一个模型不可能绕开它的结构）。

结果：均值逐位吻合；逐样本最大差 2.4e−3 dB，来自 STFT/ISTFT 在 float32 下的 舍入放大。150 个样本无一变差（最差 +4.53 dB）。

十二、局限

  • 仍然是仿真数据。α 稳定背景与突发干扰都是合成的，α 只取 1.5， 突发幅度/时长范围是设定的。导师已说明会提供实测信号，届时需重新验证。
  • 种子数仍然偏少（关键对照 3~5 个）。跨种子检验自由度很低，p 值只能作参考。 要得到可靠的效应量，建议 5~10 个种子。
  • （原缺陷，已在第六节解决）与阶段0 的对比原本含多个变量：架构与损失同时改变。 本次用"每步只改一个因素"的受控阶梯把它拆开，得到协议约 +0.9 dB、架构约 +3.3 dB （干扰帧）。但阶梯的每一档仍只跑了 1~5 个种子，R0/R1 更是单种子。
  • 波形机制的统计基础仍然偏窄：时频重叠率的相关系数基于 20 个 chirp， 且这 20 个波形来自同一张随机参数表（f0/f1/T/包络 同分布）。 "重叠率越低收益越大"这个关系在更宽的波形参数范围上是否保持，未验证。
  • 配对设计只对"波形"做了配对，信道仍与干扰实现混杂：配对模式让同一 (信道, SNR, 重复) 下的不同 chirp 看到相同干扰，但不同信道之间仍是不同的干扰实现。 因此第七节里"信道分层"的离散度（SD 0.44 dB）不能直接解读为信道效应。
  • 效应量本身很小，实用价值有限：脉冲感知分支平均只带来 +0.13（干净帧）/ +0.79（干扰帧）dB，且 96% 的方差来自样本间波动。 论文口径应写成"形成判别能力（AUC 0.95）但性能贡献有限"，不应声称"显著提升"。
  • λ₂ 由量级校准确定，不是完整网格搜索（只对照 0.05 与 0.5）。
  • 突发干扰直接叠加在信道输出上。若干扰发生在信道之前，经多径会展宽成一串回声突发， 难度完全不同 —— 该场景未测。
  • 降采样 4 倍对脉冲的衰减未做定量分解。脉冲经抗混叠滤波会被削弱， 而高斯噪声下同样的降采样带来 +6.19 dB 输入 SNR 增益。
  • 两个前端处理需要交代：样本中位有效长度 6,031/8,000（约 24.6% 零填充）； 降采样 4 倍把输入 SNR 从 0 dB 抬到 6.19 dB（高斯版）。
  • （第八节新增）α 扫描的 SNR 定义混杂已量化，并已用等功率重扫拆开。 分位数匹配让 α 与有效噪声功率同时变化（−16.4 vs +10.8 dB）。 8.1b 把名义 SNR 平移对应量做了等有效功率重扫，得到： α=1.2 端"收益被压低"里强度解释约 35%、尾形解释约 65%； α=1.8 端两成分符号相反（强度 −0.60 dB、尾形 +0.98 dB）。 即单调趋势真实，但未匹配的 α 扫描夸大了幅度。 剩余缺口：匹配条件只覆盖 α=1.2 与 α=1.8 两个点（α=2.0 需名义 SNR 低至 −24 dB，未做）。
  • （第八节新增）域内重训只安排了 rate=10 一个条件，且因进程被环境回收而中断。 本节的零样本矩阵与等功率重扫只能回答"分布偏移下的稳健性"与"尾形 vs 强度"， 不能区分"分布偏移造成的退化"与"该条件下方法本身的优劣"。 α=1.2 的域内重训同样缺失。脚本 run_sens_train.sh 已就绪， 但每次运行须用受管的后台机制启动（裸 nohup & 的进程会被回收）。
  • （第八节新增）"能识别 ≠ 能提升性能"的因果链未闭环。 我们证明了判别能力（AUC 0.93~0.96）跨条件几乎不变、而收益跨条件变化 0.2~1.7 dB， 也证明了收益与时频重叠率负相关；但没有做"人为制造重叠"的干预实验， 因此"重叠→收益下降"仍是相关而非因果。
  • （第八节新增）含时域分支的模型，逐样本指标无法从 checkpoint 逐位复现。 最大差 ≤0.13 dB、均值 ≤0.003 dB（纯频域模型仅 5e-5 dB）， 原因是时域通路对 1e-7 量级浮点归约差异的放大。 所有聚合指标复现误差 ≤0.001 dB，本研究结论基于聚合指标，不受影响； 但任何以逐样本 CSV 为依据的复核会看到非零残差。
