我用希尔伯特变换提取了 chirp_signal.mat 的瞬时频率，它是标准线性扫频：

归一化扫频速率实测为 0.08625 → 0.14711 cycles/sample（线性）。 只有 fs ≈ 9600 Hz 时，扫频区间才落在 信道产生/untitled2.m 里设定的 798–1500 Hz 上。

后果：intervals = [(0.10, 0.30, 0.50, 0.70)] 在 fs=24000 下取采样点 2400–7200 和 12000–16800。 这两个区间碰巧一个落在 chirp 中段、一个落在 chirp 之外（噪声区），所以结果看着正常 —— 但这是巧合。 一旦按真实 fs=9600 修正，同样的时间区间会跳到采样点 960–2880 和 4800–6720，选中的是完全不同的位置。

四、SNR 指标：存在 +6 dB 的系统性正偏差

calculate_snr_intervals 用「信号段减去另一个时段的噪声副本」来估纯信号功率。问题是：信号段的噪声和噪声段的噪声是两次独立的实现，相减后功率不是 Ps，而是

E[(s + n₁ − n₂)²] = Ps + 2Pn  →  估值 = 10·log₁₀(Ps/Pn + 2)

也就是说，即使信号功率为零，这个指标也会报出 10·log₁₀(2) = 3.01 dB —— 存在一个硬地板。

指标代码自报真实值（以 clean 为参考）偏差
输入 SNR5.14 dB−1.21 dB+6.34 dB
输出 SNR18.65 dB12.60 dB+6.04 dB
SNR 增益13.51 dB13.81 dB−0.30 dB

好消息：由于偏差在输入/输出上几乎相等，增益数字（≈13.5 dB）是基本可信的。
坏消息：绝对 SNR 值全部虚高 6 dB。如果论文里写"输入 SNR 5.79 dB、输出 18.26 dB"，审稿人按 clean 真值一算就会对不上。 另外 7 dB 的门限是加在这个带偏指标上的，等价于真实的 ~1 dB 门限，几乎任何输出都能通过 —— 所谓"智能判断是否满足要求"实际上形同虚设。

五、根本问题仍未解决：单一固定目标

DenoiseDataset.__init__ 里 self.clean_signal 是同一个 chirp（9600 点 + 8949 点零填充）， 对全部 6784 个样本反复使用。训练集里只有一个干净波形。

网络因此只需学会"输出这个 chirp"，而不需要学会"去噪"。 我在 27 个存档结果上复算：
· 27 个输出两两相关系数 = 0.977
· 27 个输入两两相关系数 = 0.026

输入彼此几乎不相关，输出却几乎一模一样 —— 因为目标本来就只有一个。 这个实验设计没有能力区分"模型真的会降噪"和"模型背下了这个波形"，两者会给出同样漂亮的数字。

这是本工作最需要优先解决的问题。只要目标信号仍然唯一，无论把网络改得多好、把指标算得多准，结论都站不住。

六、预处理里两个"修对了方向但引入了新问题"的地方

1. 逐样本 99 分位归一化，会放大低信噪比样本的噪声

对每个样本各自除以自己的 99 分位幅度，意味着：

  • 输入的绝对幅度信息被完全抹掉，输入与目标之间的相对电平关系不复存在；
  • 那些 rms 只有 5e-13（信号已被信道衰减到噪声以下）的样本，归一化后噪声被放大到 ±1，而目标仍是干净的 ±1 chirp —— 等于在教模型"从纯噪声里凭空生成 chirp"。这正是幻觉式生成器的训练配方。

建议：按整批统计做统一的尺度变换，或直接用真实 SNR 分层，而不是逐样本自归一化。

2. 长度补齐用"复制信号尾巴"，会制造伪信号

noise_padding = noisy_signal[-pad_len:] 把信号最后 pad_len 个点原样复制到末尾。 对 4 月批（9600 → 18549）要复制 8949 点，等于把信号后 93% 又贴了一遍，产生明显的周期性和拼接不连续。 对 te_signal（17599 → 18549）复制 950 点，影响较小。

七、仍然存在的模型结构 / 工程问题

位置问题
input_norm = LayerNorm(18549) 单个 LayerNorm 占 37,098 参数，是全模型 99,005 参数的 37.5%。 一个"轻量化"模型近四成参数花在全长度归一化上，并且把模型锁死在固定输入长度。建议改为逐帧/逐通道归一化，或直接去掉。
final_fusion 的 tanh 输出被硬限幅在 (−1, 1)。当前目标经归一化后幅值 ≈ ±1.0004，勉强够用；但一旦目标波形的波峰因数变化，模型就永远拟合不了。 同时这个 tanh 把前面 residual 残差路径整个压平，"保持信号主体结构"的设计失效。
_init_weights 在 __init__ 末尾对所有 Conv1d 做 kaiming 初始化，会覆盖前面刚设好的 signal_preservation.weight = 1.0 / bias = 0.0。那段恒等初始化是死代码。
微调分支 max_finetune_iterations = 2 时循环最多走到 iteration=2，而微调只在 iteration < max 时调用， 即只会传入 iteration_num=1。iteration_num==2 和 else 两个分支永远不会执行，是死代码。
频域分支 噪声估计 mask 与幅度 mask 两级 Sigmoid 级联相乘，过度压制；相位修正系数 0.1 为硬编码常数。
损失函数 noise_reduction 比值项与主 L1 项优化方向相同，属冗余；smoothness_loss 建议改为对残差 (denoised − noisy) 的 L1，更贴合降噪目标。
训练循环 except Exception: continue 吞掉一切异常，avg_loss 可能只由极少数 batch 算出；torch.save(model.cpu()...) 后 model.to(device) 每次刷新最佳模型都要搬两趟；无随机种子，np.random.normal 补齐不可复现。
数据加载 __getitem__ 每次 sio.loadmat 全量读盘，6784 个文件 × 100 epoch，无缓存、无预处理。
