数据生成链路诊断

对象：D:\project\信道产生\Input_PE.m · PEsim_main_parfor.m · untitled2.m（你改的版本）· chirp_signal.mat
方法：对全部 .mat 做二进制解析 + 纯 Python FFT 频谱分析 + 匹配滤波
一句话结论：老师原来的代码是自洽的 —— 信道定义在 24000 Hz，chirp 在 9600 Hz，中间必须做一次重采样。 你把 fct 从 3 改成 10 提速，但 fl/fct 是直接当 DFT 的 bin 索引用的， 所以信道通带从 798~1500 Hz 整体下移到了 237~447 Hz；再加上重采样被删掉， 现在 chirp 的频带和信道的频带完全不重叠 —— 信道算得再准，信号也过不去。

一、老师的代码是怎么自洽的

参数值含义
Len8000冲激响应长度（点数）
fl / fh798 / 1500 Hz换能器工作频带
fct3 Hz频率步进
Vfre798:3:1500235 个频点（我在 data1/sim_para1.mat 里核对过，确实是 235 点、3 Hz 步长）
写入位置F(fl/fct : fh/fct)= F(266:500)
反推采样率：8000 点 DFT 的第 k 个 bin 对应频率 k·(fs/8000)。 要让 bin 266 对应 798 Hz，必须有 fs/8000 = 3 Hz，即 fs = 24000 Hz。
反过来验证：500 × 3 = 1500 Hz ✓ —— 与 fh 严丝合缝。
所以 fl/fct 之所以能当 bin 用，是因为 fct 恰好等于频率分辨率 df = 3 Hz。这是一个隐藏的耦合。

三、chirp 在 9600 Hz，信道在 24000 Hz

我对 chirp_signal.mat（9600 点）做了 FFT：

信号99% 能量归一化频带×9600 Hz×24000 Hz
chirp_signal0.08337 ~ 0.15607800 ~ 1498 Hz2001 ~ 3746 Hz
老师信道通带0.03325 ~ 0.06250319 ~ 600 Hz798 ~ 1500 Hz
决定性验证：把 chirp 的归一化频带除以 2.5（即 9600 → 24000 Hz 的重采样比）：
0.08337 / 2.5 = 0.03335，0.15607 / 2.5 = 0.06243
与老师信道通带 0.03325 ~ 0.06250 吻合到小数点后第三位。

结论：chirp 文件确实是 9600 Hz 采样的，必须先 resample(chirp, 24000, 9600) 才能和信道卷积。

你在 Gemini 指导下删掉了 resample（代码里那行注释写着"彻底废除物理错误的 resample"）—— 那一步不是物理错误，它正是采样率转换。删掉之后，两个信号的归一化频带相差 2.5 倍，卷积结果为零。

四、实测：现在的数据里发生了什么

上面那张频谱图是三条曲线的实测结果，横轴归一化频率：

  • 干净 chirp：0.083 ~ 0.156 一条平坦的通带（线性调频的典型谱形），带宽 99% 集中在此。
  • 你的 channel_H：尖峰在 0.010 ~ 0.019，其他地方低 4 个数量级。与 chirp 零重叠。
  • 含噪信号：能量 62 ~ 83% 压在你的信道那个错误频带（0.0099~0.0187），谱密度是旁带的 30 ~ 40 倍； chirp 所在的 0.083 ~ 0.156 处只有一个约 5 倍于本地底噪的小台阶。

五、怎么修

修 1信道生成：bin 索引必须与 fct 解耦

fs  = 24000;  Len = 8000;
df  = fs/Len;                        % 3 Hz —— 与原代码一致
fl  = 798;    fh = 1500;
fct = 10;                            % 仍然稀疏，省 RAM 调用
Vfre = fl:fct:fh;                    % 71 点
% ... 逐点算 Vpress ...
Vfull = interp1(Vfre, Vpress, fl:df:fh, 'linear', 'extrap');   % 插值回 3 Hz 网格
F = zeros(1, Len);
F(round((fl:df:fh)/df)) = Vfull;     % ★ = 266:500，与 fct 无关
H = ifft(F, 'symmetric');            % 实数冲激响应

一句话：bin 索引由 fs 和 Len 决定，绝不能用 fl/fct。

修 2数据生成：先把 chirp 重采样到 24000 Hz

clean24 = resample(clean, 24000, 9600);    % ★ 9600 → 24000，时长不变
y       = conv(clean24, channel_H);        % 现在频带对齐了
noisy   = y + randn(size(y)) * sqrt(Py/10^(snr/10));

修 3重新生成后必须自检

  1. 新的 channel_H 的 99% 能量应落在归一化频率 0.0333 ~ 0.0625（不是 0.0099~0.0187）。
  2. 新的含噪信号的信号成分应在 0.0333 ~ 0.0625，而不是 0.0834 ~ 0.1561。
  3. 与 clean 的互相关峰值应在 0 延迟附近（而非 8000），且波形应体现时延扩展。

六、关于"跑得慢"

方法加速比代价
把 fct 从 3 改到 103.3×（235 → 71 次 RAM 调用）频率采样变稀疏，必须插值补偿；而且你这次把 bin 索引一起改错了
开 parfor 并行≈ 核数倍（4 核 4×，8 核 8×）不牺牲任何精度
放粗 RAM 的 dz 网格（dz = 1500/freq/20 → /10）约 2×深度分辨率略降
老师的文件名就叫 PEsim_main_parfor.m，里面 parpool('local', core_number) 那三行是被注释掉的 —— 他本来就是打算并行的。把这三行打开、把内层 for mm 改成 parfor mm， 比减频率点划算得多，而且不用动任何物理参数。

建议：并行 + 保持 fct=3（或者 fct=5 再插值），不要为了提速去改 bin 映射。
